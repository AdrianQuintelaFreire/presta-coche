# PrestaCoche

Plataforma web de alquiler de vehículos entre particulares desarrollada en PHP y MySQL.

Permite a los usuarios publicar vehículos, realizar reservas y gestionar perfiles, incluyendo validación de vehículos y usuarios por parte de un administrador.

## Tecnologías
- HTML5
- CSS3 / SASS con metodología BEM
- JavaScript
- PHP
- MySQL

## Estructura del proyecto
prestacoche/
├── actions/
├── app/
├── config/
├── includes/
├── pages/
├── public/
├── routes/
└── storage/

## Requisitos
- PHP 8+
- MySQL
- XAMPP (ou Apache + MySQL)

## Instalación
1. Clonar o descargar el proyecto.
2. Copiar a carpeta en `htdocs`, la ruta sería `C:\xampp\htdocs`.
3. Importar o ficheiro `prestacoche.sql` dentro phpMyAdmin.
4. Abrir:
   http://localhost/prestacoche/public/

## Funcionalidades
- Registro y login
- Publicación de vehículos
- Reserva de vehículos
- Gestión de perfil
- Validación por administrador

## Usuarios
- Usuario no registrado
- Usuario registrado validado o no
- Administrador
